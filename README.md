## ✨ Key Features

### Interactive JavaScript Features
- 🤖 **AI Chatbot Widget** — Floating assistant with keyword-based responses, quick-reply buttons, typing indicators, and real-time clock timestamps
- 🎨 **Dark/Light Theme Toggle** — Persistent theme preference via localStorage
- 📊 **Animated Stats Counter** — Numbers count up when scrolled into view
- ⌨️ **Typing Effect** — Hero section animated text carousel
- 🔍 **Portfolio Filter** — Category-based filtering with smooth fade animations
- ❓ **FAQ Accordion** — Expandable/collapsible question panels
- 💰 **Pricing Toggle** — Switch between monthly and yearly billing
- 📱 **Mobile Hamburger Menu** — Slide-out drawer navigation
- ⬆️ **Back to Top Button** — Appears after scrolling 500px
- 🔔 **Toast Notifications** — Non-intrusive success/error messages
- ✨ **Scroll Reveal Animations** — Elements fade in as you scroll

### Forms & Validation
- ✅ **Contact Form** — Real-time validation for name, email, subject, and message
- ✅ **Newsletter Forms** — Multiple newsletter signup points (footer, contact page, blog)
- ✅ **Form Success States** — Visual confirmation after submission

### Design & UX
- 🌓 **Dual Theme** — Full dark mode (default) + light mode support
- 📐 **CSS Custom Properties** — Centralized design system with variables
- 🎯 **Glassmorphism Effects** — Frosted glass cards and overlays
- 🌊 **Smooth Animations** — Hover effects, transitions, and micro-interactions
- ♿ **Accessibility** — ARIA labels, keyboard navigation, focus-visible outlines, reduced-motion support
- 🖨️ **Print Styles** — Clean print layout

## 🚀 Getting Started

### Local Development
1. Clone or download the repository
2. Open any `.html` file in your browser
3. No build step required — pure HTML/CSS/JS

### Deployment
The site is deployed on **Netlify** (or GitHub Pages / Vercel):
- Drag-and-drop the folder to Netlify
- Or push to GitHub and connect to Vercel/Netlify
