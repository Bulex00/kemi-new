## 📋 Project Overview

**Bulex Digital** is a modern digital agency website designed for a Lagos-based technology and digital services brand,The platform showcases services including:

- Web Development
- Mobile Application Development
- UI/UX Design
- Branding & Identity
- SEO & Content Strategy
- Digital Marketing

The project demonstrates the ability to build a modern, responsive, accessible, and interactive multi-page website using standard frontend technologies.

## ✨ Key Features

### 🤖 Interactive JavaScript Features

| Feature | Description |
|---------|-------------|
| 💬 **AI Chatbot Widget** | Floating assistant with keyword-based responses, quick-reply buttons, typing indicators, and real-time timestamps |
| 🌓 **Dark/Light Theme Toggle** | Persistent theme preference using `localStorage` |
| 📊 **Animated Statistics Counter** | Numbers count up when scrolled into the viewport |
| ⌨️ **Typing Effect** | Animated text carousel in the hero section ("Websites, Brands, Apps, Experiences") |
| 🔍 **Portfolio Filter** | Category-based project filtering with smooth fade animations |
| ❓ **FAQ Accordion** | Expandable/collapsible question panels on the Pricing page |
| 💰 **Pricing Toggle** | Switch between monthly and yearly billing with animated price updates |
| 📱 **Mobile Hamburger Menu** | Slide-out drawer navigation for mobile devices |
| ⬆️ **Back-to-Top Button** | Appears after scrolling 500px with smooth scroll behavior |
| 🔔 **Toast Notifications** | Non-intrusive success and status messages |
| ✨ **Scroll Reveal Animations** | Content animations triggered during scrolling |

### 📝 Forms & Validation

- ✅ **Contact Form** — Real-time validation for name, email, subject, and message fields
- ✅ **Newsletter Signup** — Multiple newsletter forms across pages (footer, contact, blog)
- ✅ **Form Success States** — Visual confirmation after successful submission
- ✅ **User-Friendly Error Messages** — Clear inline validation feedback

### 🎨 Design & UX

- 🌗 **Dual Theme** — Full dark mode (default) + light mode support
- 📐 **CSS Custom Properties** — Centralized design system for colors, spacing, typography
- 🧊 **Glassmorphism Effects** — Frosted glass cards and overlays
- 🌊 **Smooth Animations** — Hover effects, transitions, and micro-interactions
- ♿ **Accessibility** — ARIA labels, keyboard navigation, focus-visible outlines, reduced-motion support
- 🖨️ **Print Styles** — Clean print layout

## 🚀 Getting Started

### Prerequisites

- Bulex Digital is a static frontend project
- No build tools or dependencies required

### Local Development

**Option 1 — Open directly:**
```bash
# Simply open index.html in your browser
open index.html
```

**Option 2 — Local server:**
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Then visit http://localhost:8000
```

## 📱 Responsive Breakpoints

| Breakpoint | Target | Key Changes |
|------------|--------|-------------|
| **< 576px** | Mobile | Single column, hamburger menu, stacked layouts |
| **576px – 767px** | Large mobile | 2-column grids begin, larger typography |
| **768px – 1023px** | Tablet | Desktop nav appears, 2-3 column grids |
| **1024px+** | Desktop | Full layout, 3-4 column grids, all features visible |
**The website adapts its layout, navigation, typography, cards, forms, and interactive components to different screen sizes.**
